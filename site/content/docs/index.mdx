Treenail is a planning-skills pack that gives your coding agent a durable
**decision, risk, and task** record — a planning spine that lives in your repo
and outlives any single session.

## Start here

- **[Getting Started](/docs/getting-started)** — prerequisites, installing for
  your agent (npx, plugin, or manual copy), and your first skill run.
- **[Core Concepts](/docs/core-concepts)** — the planning spine, the
  decision/risk/task model, scopes, INDEX discipline, and the `O(active work)`
  read path.

## What lives here

The documentation is a single, unversioned set that tracks `main`. The
**Pipeline** and **Record Conventions** sections pair an authored overview with
per-skill and per-record reference pages generated at build time from the
canonical repo files (`skills/*/SKILL.md` and `docs/CONVENTIONS-SPEC.md`), so
those pages never drift from the product. The **Reference** section is authored.
