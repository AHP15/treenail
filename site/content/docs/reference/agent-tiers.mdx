---
title: Agent support tiers
description: What to expect running Treenail on Claude Code, Codex CLI, and opencode.
---

Treenail's flagship skills are built around structured interviews and agentic
multi-step sessions. **All three supported agents run the complete pipeline
correctly** — what differs is the interview surface, not the fidelity. This
matrix is validated end-to-end, not aspirational.

| Agent | Tier | What to expect |
| ----- | ---- | -------------- |
| **Claude Code** | **Best** | Structured selectable-option interviews and native skill-to-skill chaining — the environment Treenail is dogfooded in daily. |
| **Codex CLI** | **Full** | Complete pipeline fidelity. Interview questions arrive as prose to answer in free text, rather than a selectable option list. |
| **opencode** | **Full** | Complete pipeline fidelity, verified even on the zero-config free model. Interviews arrive as prose; headless runs need `--auto` to approve file writes. |

The one-line version: **best on Claude Code, fully functional on Codex CLI and
opencode.** The record formats, INDEX discipline, greenfield bootstrap, interview
pushback, and drift detection all hold on every agent — the only difference is
whether interview questions render as a selectable option list or as prose you
answer in free text.
