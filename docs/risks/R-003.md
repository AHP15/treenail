## R-003: Dogfooding friction reinstates shadow editing in ~/.claude, recreating drift

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-003 makes every skill tweak an edit-in-repo, rebuild, reinstall cycle where today it is a direct file edit. Under deadline pressure the owner will edit the installed copy in ~/.claude "just this once", the installed copy silently becomes the real source, and the next `update` overwrite (D-010) destroys those live edits — the exact drift D-003 was meant to eliminate, plus data loss.
- **Disposition rationale**: Residual acceptable: the dev-mode symlink install makes the owner's edits land in the repo (removing the edit-in-place temptation), and update now warns + backs up before overwriting any local edit — the drift-and-data-loss path is closed, not merely reduced.
- **Action**: Accept — residual bounded and acceptable; mitigated by T-016 (dev-mode symlink install) and T-015 (checksum manifest + warn/backup on update), both shipped.
- **Related decisions**: D-003, D-010
