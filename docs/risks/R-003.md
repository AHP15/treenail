## R-003: Dogfooding friction reinstates shadow editing in ~/.claude, recreating drift

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: D-003 makes every skill tweak an edit-in-repo, rebuild, reinstall cycle where today it is a direct file edit. Under deadline pressure the owner will edit the installed copy in ~/.claude "just this once", the installed copy silently becomes the real source, and the next `update` overwrite (D-010) destroys those live edits — the exact drift D-003 was meant to eliminate, plus data loss.
- **Disposition rationale**: High likelihood — the edit-in-place temptation is a daily-workflow force — and D-003's own text already anticipates the symlink escape hatch; a cheap guard removes the drift-and-data-loss path without changing the decision.
- **Action**: Give the owner's machine a dev-mode install (symlink from the provider skill dir to the repo checkout) so 'editing the installed copy' edits the repo; additionally have `update` detect locally modified files via an install-time checksum manifest and warn instead of silently overwriting (shared guard with R-011). Mitigated by T-016 (dev-mode symlink install) and T-015 (checksum manifest + overwrite warning).
- **Related decisions**: D-003, D-010
