## R-029: The guide→README migration dropped the scenario walkthroughs, leaving no in-repo end-to-end onboarding path for first external adopters

- **Severity**: low
- **Likelihood**: medium
- **Disposition**: defer
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-027's curated migration kept the artifact-layout tree, the
  per-skill pipeline narrative, and the cadence table but dropped the guide's
  "new project" and "feature on existing project" step-by-step walkthroughs. A
  first-time external user — an adoption event the retro flags under Watch-for
  #5 — now has no single in-repo place showing the concrete run order end to
  end; they must reconstruct it from the pipeline diagram plus each individual
  SKILL body. The failure is silent (nobody files a bug for "I couldn't figure
  out where to start") and only visible as adoption friction once the repo goes
  public.
- **Disposition rationale**: Low severity, and the failure only manifests at
  adoption — which has not begun pre-v1 — so it fits the adoption-triggered
  defer pattern of R-002/R-013/R-025. Reinstating the walkthroughs speculatively
  before any user signals the gap would re-bloat the README that D-027 just
  trimmed.
- **Action**: Defer trigger: the first external getting-started report (a GitHub
  issue about not knowing the run order / where to start), OR the start of the
  deferred public-launch onboarding-docs pass — whichever comes first. At that
  trigger, reinstate a concise end-to-end walkthrough (the two scenarios) in the
  README or a `docs/` onboarding page.
- **Related decisions**: D-027
