## R-015: Skills fail mid-run when Python 3 is absent despite the install-time warning

- **Severity**: low
- **Likelihood**: medium
- **Disposition**: mitigate
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: D-009 has the installer warn when Python 3 is missing, but nothing stops the user from proceeding (or from later breaking their Python install). The failure then surfaces deep inside a skill run — e.g. challenge-me completes a full interview and only fails at mint-id time — losing session work and presenting as a cryptic script error rather than a clear missing-dependency message.
- **Disposition rationale**: Low severity overall, but the specific failure — losing a completed interview at mint time — is disproportionately painful and cheap to prevent by moving the check earlier.
- **Action**: Skills that end in a scripted write (mint-id, reindex) preflight the Python interpreter at skill start, before any interview work; on failure they stop with a clear 'Python 3 required — see install docs' message instead of a mid-run traceback. Mitigated by T-021 (Python preflight at skill start).
- **Related decisions**: D-009
