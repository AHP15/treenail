## R-043: Experimental project-level config can create team divergence before project-level skills are generally supported

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: mitigate
- **Date**: 2026-07-10
- **Date resolved**:
- **Description**: D-035 introduces a limited project-level substrate while D-008 keeps normal installs user-level. A teammate can commit or consume experimental project agent config while others run older Treenail versions, use only user-level installs, or have different manifest/prune behavior, making the repo's agent behavior diverge before the project has a formal shared-version story.
- **Disposition rationale**: Medium severity and medium likelihood justify a
  guard because D-035 intentionally opens a small project-level surface before
  the broader D-008 deferral is reversed. The decision can stand if
  experimental project config is visibly versioned and isolated from normal
  shared project-level skills.
- **Action**: Keep D-008 and D-035. Guard: project-level experimental installs
  record the Treenail package version, adapter id, and experimental status in
  the manifest, and installer/update output warns when the repo contains
  experimental project config from a different Treenail version or an adapter
  that is not available locally. Do not document experimental project config as
  a supported team workflow until a later project-level install decision
  replaces D-008's v1 boundary. Mitigated by T-059 and T-060.
- **Related decisions**: D-008, D-035
