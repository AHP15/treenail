## R-005: No end-to-end behavioral validation exists for any agent; v1 can ship broken on advertised targets

- **Severity**: high
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: D-012's CI validates the Python scripts and that dist/ is in sync with source — nothing validates that an installed skill actually runs the pipeline end-to-end on Claude Code, opencode, or Codex. Skill behavior lives in prose interpreted by three different agents, so a build that is textually correct can still be behaviorally broken (skill not discovered, frontmatter ignored, script invocation phrasing not followed), and nothing in the v1 cut (D-015) would catch it before users do.
- **Disposition rationale**: High severity and high likelihood — nothing in CI exercises behavior, and prose-interpreted skills break in ways textual checks cannot see. A manual pre-release behavioral pass is the minimal guard that keeps D-015's cut intact.
- **Action**: Define a release-gate smoke checklist: on each of the three agents, install via the real channel, verify skill discovery, and run at least one scripted-runtime skill (mint-id path) and one interactive skill end-to-end. Make passing it a v1 ship criterion; automate later only if the manual pass proves too costly. Mitigated by T-028 (release-gate smoke checklist).
- **Related decisions**: D-004, D-012, D-015
