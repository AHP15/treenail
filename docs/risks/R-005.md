## R-005: No end-to-end behavioral validation exists for any agent; v1 can ship broken on advertised targets

- **Severity**: high
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-012's CI validates the Python scripts and that dist/ is in sync with source — nothing validates that an installed skill actually runs the pipeline end-to-end on Claude Code, opencode, or Codex. Skill behavior lives in prose interpreted by three different agents, so a build that is textually correct can still be behaviorally broken (skill not discovered, frontmatter ignored, script invocation phrasing not followed), and nothing in the v1 cut (D-015) would catch it before users do.
- **Disposition rationale**: Residual acceptable: the release-gate smoke checklist exists and a three-agent pass is recorded for the RC (T-028), and passing it is a v1 ship criterion; the residual is the manual re-run obligation, to be automated later only if it proves too costly (per this risk's own triage).
- **Action**: Accept — behavioral validation now exists and gates v1; mitigated by T-028 (release-gate checklist + recorded three-agent pass), shipped.
