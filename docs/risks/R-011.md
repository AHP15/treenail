## R-011: Update silently destroys user edits to installed skills

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: Installed skills are plain markdown that invites tinkering, and D-010's managed-overwrite model deletes any local edits on `update` with no backup and no warning diff. "Fork to customize" is documented, but the first sign most users get is losing an afternoon of prompt tuning — a reliable generator of angry issues and lost trust.
- **Disposition rationale**: Residual acceptable: update now writes a checksum manifest, diffs installed files, and warns + requires confirmation + timestamped backup before overwriting local edits — the silent data-loss path is removed (D-010's no-merge model stands).
- **Action**: Accept — silent overwrite eliminated; mitigated by T-015 (checksum manifest + warn/backup on update), shipped and verified end-to-end.
- **Related decisions**: D-010
