## R-011: Update silently destroys user edits to installed skills

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: Installed skills are plain markdown that invites tinkering, and D-010's managed-overwrite model deletes any local edits on `update` with no backup and no warning diff. "Fork to customize" is documented, but the first sign most users get is losing an afternoon of prompt tuning — a reliable generator of angry issues and lost trust.
- **Disposition rationale**: High likelihood — plain-markdown skills invite tinkering, and the first silent data loss costs trust permanently. D-010's no-merge model stands; the guard removes only the *silent* part.
- **Action**: Installer writes a checksum manifest at install time; `update` diffs installed files against it and, on local modifications, warns and requires confirmation (or backs the modified files up to a timestamped directory before overwriting). Shares the manifest mechanism with R-003's guard. Mitigated by T-015 (checksum manifest + warn/backup on update).
- **Related decisions**: D-010
