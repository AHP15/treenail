## R-001: Brand collision with keel.sh / keel.so forces a rename after adoption

- **Severity**: medium
- **Likelihood**: low
- **Disposition**: defer
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: keel.sh (Kubernetes deployment tool) and keel.so (funded backend-platform company) are established dev-tool brands. If Keel gains traction and later monetizes (D-002's Pro tier), a trademark complaint — most plausibly from the commercial keel.so — could force a rename exactly when the name has accumulated value: npm package, marketplace listing, README links, and user muscle memory all break at once.
- **Disposition rationale**: Medium severity but low likelihood, and the cost only materializes if the brand accumulates commercial value; renaming pre-adoption stays cheap, so this needs a revisit point, not action now.
- **Action**: Defer trigger: revisit when Pro-tier/monetization work begins (per D-002's model), or immediately upon any trademark communication from keel.so/keel.sh — whichever comes first.
- **Related decisions**: D-001
