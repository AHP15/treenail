## R-035: The support-bar pass criteria are weak and subjective, so a non-conforming agent can still pass

- **Severity**: low
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-08
- **Date resolved**:
- **Description**: D-031 defines "passed" as the pipeline running with records auditing clean (0 blockers) and "the interview protocol intact." Both criteria are softer than they look. The spike itself recorded Codex producing cosmetically non-conforming output (Evidence anchors space-separated instead of comma-separated) that *audited clean* — so "0 blockers" demonstrably admits output that deviates from house style and could bite downstream tooling later. "Protocol intact" (one question at a time, recommendation-first, pushback) is a human judgment with no checklist, so two people validating the same agent could reach opposite verdicts. The bar reads rigorous but under-specifies pass/fail, permitting inconsistent or false-positive admissions to the advertised list.
- **Disposition rationale**: Low severity — the worst case is a cosmetically non-conforming agent landing on the list, which is tolerable and self-correcting at the next validation. Not worth a dedicated gate.
- **Action**: none — accept the residual. If it ever bites, tighten the pass checklist *inside* the R-034 validation-record template (where the criteria already live) rather than standing up a separate mechanism.
- **Related decisions**: D-031
