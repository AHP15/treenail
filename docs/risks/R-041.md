## R-041: Surface dossiers can go stale before graduation and validate an obsolete agent contract

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: mitigate
- **Date**: 2026-07-10
- **Date resolved**:
- **Description**: D-034 requires a dated, source-backed dossier before parity validation, but the target products are external and fast-moving. A candidate can be implemented against an old install path, config directory, permission model, or headless/TUI mode, then graduate on a dossier that is historically accurate but no longer describes the current agent surface.
- **Disposition rationale**: Medium severity and medium likelihood fit a
  freshness guard rather than a decision change. Dossiers are still the right
  evidence shape, but they need a recency rule before they can support
  graduation.
- **Action**: Keep D-034. Guard: require the packaged parity-validation record
  to re-confirm the dossier's external facts during the validation run. The
  record must cite the current official source URLs and observation date for
  install path, config directory, instruction format, interaction mode, and
  sandbox/permission behavior; a stale or unreachable source blocks graduation
  until refreshed. Mitigated by T-055, T-056, T-061, T-062, T-063, and T-064.
- **Related decisions**: D-034
