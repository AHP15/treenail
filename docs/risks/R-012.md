## R-012: Frozen per-project conventions require scripts to stay backward-compatible forever, with no version marker to dispatch on

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-010 freezes each project's copied conventions at adoption time while ~/.keel scripts and skills upgrade globally. Nothing in a project's docs/ records which spec version it was created under, so a future reindex.py or audit.py that changes record parsing cannot detect old-format projects — it will either corrupt their INDEX files or refuse to run, and the failure lands in the user's own planning records, the highest-trust data Keel touches.
- **Disposition rationale**: Residual acceptable: adoption stamps a spec-version marker (Spec-version line + docs/.treenail-version) and the record-parsing scripts refuse loudly on an unknown spec version instead of guessing — a future format change can no longer silently corrupt an old-format project's records.
- **Action**: Accept — old-format projects are detectable and safely refused; mitigated by T-022 (spec-version marker + loud refusal), shipped.
- **Related decisions**: D-010
