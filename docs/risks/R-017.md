## R-017: Prepack/dist bundling has no owning task, so every published package fails at distRoot()

- **Severity**: high
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-018 fixes `files` to include `lib/` but explicitly defers prepack/dist bundling "to T-004" — yet T-004 is scoped as publishing a *placeholder* 0.0.x, and no task's acceptance says "the published package contains dist/ and `npx keel-skills install` works from it". Until that wiring exists, every published version crashes at `distRoot()` with "built dist/ not found — run `python3 build.py`", nonsense advice for an npx user. The gap can survive to v1: T-029 can satisfy "0.1.0 published" with a bare `npm publish`, and the T-028 release gate could smoke-test from a repo checkout — the one environment where distRoot() succeeds anyway — masking the failure.
- **Disposition rationale**: Residual acceptable: prepack bundles dist/ into the published package and a clean-environment tarball smoke (part of the release gate) verifies `npx treenail install` works from the packed artifact — the distRoot() crash every npx user would hit is closed and continuously checked.
- **Action**: Accept — published-package install verified from a clean env; mitigated by T-033 (prepack bundles dist + tarball verify) and T-034 (clean-env tarball smoke in the release gate), both shipped.
- **Related decisions**: D-018, D-007
