## R-007: Plugin-marketplace installs bypass the installer, so ~/.keel is never provisioned

- **Severity**: high
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Related decisions**: D-006, D-007
- **Action**: Accept — provisioning gap closed; mitigated by T-019 (plugin bundles the runtime + SessionStart bootstrap) and T-020 (runtime-missing failure message), both shipped.
- **Date archived**: 2026-07-04
- **Summary**: D-006 makes skills depend on scripts/templates in ~/.keel, which only the npx installer creates. Residual acceptable: the plugin build bundles the runtime and provisions ~/.treenail on first session, and every scripted-invocation failure states the runtime-missing backstop message — a plugin-only user no longer hits an unprovisioned runtime.
