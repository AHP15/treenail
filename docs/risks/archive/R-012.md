## R-012: Frozen per-project conventions require scripts to stay backward-compatible forever, with no version marker to dispatch on

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-04
- **Related decisions**: D-010
- **Action**: Accept — old-format projects are detectable and safely refused; mitigated by T-022 (spec-version marker + loud refusal), shipped.
- **Date archived**: 2026-07-04
- **Summary**: D-010 freezes each project's copied conventions at adoption time while ~/.keel scripts and skills upgrade globally. Residual acceptable: adoption stamps a spec-version marker (Spec-version line + docs/.treenail-version) and the record-parsing scripts refuse loudly on an unknown spec version instead of guessing — a future format change can no longer silently corrupt an old-format project's records.
