## R-015: Skills fail mid-run when Python 3 is absent despite the install-time warning

- **Severity**: low
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-04
- **Related decisions**: D-009
- **Action**: Accept — the painful mid-run failure is prevented; mitigated by T-021 (Python preflight at skill start), shipped.
- **Date archived**: 2026-07-04
- **Summary**: D-009 has the installer warn when Python 3 is missing, but nothing stops the user from proceeding (or from later breaking their Python install). Residual acceptable: skills that end in a scripted write now preflight Python 3 at skill start and stop with a clear 'Python 3 required' message before any interview work, so a completed interview can no longer be lost to a mint-time traceback.
