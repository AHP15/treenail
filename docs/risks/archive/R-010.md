## R-010: Windows is claimed officially supported without Windows CI or a path-portability audit

- **Severity**: high
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Related decisions**: D-009, D-012, D-015
- **Action**: Accept — Windows is now actually tested in CI; mitigated by T-005 (mint-id Python port), T-006 (POSIX-assumption audit), T-024 (Windows CI runner), all shipped.
- **Date archived**: 2026-07-04
- **Summary**: D-009 promises native-Windows support, but the _shared scripts were written and tested only on macOS — POSIX path assumptions (~ expansion, forward slashes, case sensitivity), Git Bash vs cmd differences, and CRLF handling are all unaudited, and D-012's CI has no Windows runner. Residual acceptable: the mint-id path is a portable Python port, the _shared scripts were audited for POSIX assumptions, and a Windows CI runner now exercises the script tests + installer smoke and gates v1 — the 'zero Windows testing' gap that made D-009's support claim unearned is closed.
