## R-011: Update silently destroys user edits to installed skills

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: accept
- **Date**: 2026-07-04
- **Related decisions**: D-010
- **Action**: Accept — silent overwrite eliminated; mitigated by T-015 (checksum manifest + warn/backup on update), shipped and verified end-to-end.
- **Date archived**: 2026-07-04
- **Summary**: Installed skills are plain markdown that invites tinkering, and D-010's managed-overwrite model deletes any local edits on `update` with no backup and no warning diff. Residual acceptable: update now writes a checksum manifest, diffs installed files, and warns + requires confirmation + timestamped backup before overwriting local edits — the silent data-loss path is removed (D-010's no-merge model stands).
