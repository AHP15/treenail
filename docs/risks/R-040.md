## R-040: Bundled experimental adapters can break the supported package path even when users never opt in

- **Severity**: high
- **Likelihood**: medium
- **Disposition**: mitigate
- **Date**: 2026-07-10
- **Date resolved**:
- **Description**: D-034 puts experimental adapters in committed `dist/` and the npm package so the real packaged path can be validated. That also means a malformed candidate output, stale generated file, or packaging regression can affect `prepack`, smoke install, tarball contents, or supported-agent installs before any user passes `--experimental`.
- **Disposition rationale**: High severity with medium likelihood is worth an
  immediate packaging guard, but it does not invalidate bundling candidates in
  the package for honest validation. The key is to prove the default supported
  install path stays clean when experimental outputs exist.
- **Action**: Keep D-034. Guard: extend packaging validation so the default
  build, prepack, tarball, install, update, and smoke paths are exercised with
  experimental adapters present but not selected. The check must fail if
  experimental files are installed by default, if an experimental manifest
  changes supported-agent output, or if a malformed experimental adapter breaks
  packaging for supported agents. Mitigated by T-057 and T-058.
- **Related decisions**: D-034
