## R-008: Multi-channel installs create version skew between skill text and the ~/.keel runtime

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-04
- **Date resolved**:
- **Description**: D-014's lockstep versioning assumes one install path, but D-007 ships three: marketplace plugins update on Claude's cadence while ~/.keel updates via the CLI. A user with both channels can hold v0.3 skill text calling a script flag that the v0.2 scripts in ~/.keel don't have (or vice versa), producing failures that neither version alone would show and that are hard to reproduce from a bug report.
- **Disposition rationale**: Residual acceptable: the build stamps each skill's version and the shared scripts compare it against ~/.treenail/VERSION, converting silent multi-channel skew into a one-line actionable error; D-014's lockstep model is intact.
- **Action**: Accept — skew is now surfaced, not silent; mitigated by T-017 (version stamp into skill output) and T-018 (runtime version handshake), both shipped.
- **Related decisions**: D-007, D-014
