## R-009: The keel-skills npm name is unreserved until first publish

- **Severity**: low
- **Likelihood**: low
- **Disposition**: mitigate
- **Date**: 2026-07-02
- **Date resolved**:
- **Description**: D-001 selects `keel-skills` based on a registry availability check, but npm names are claimed only by publishing. If the repo goes public (with the name in the README) before the package is published, a squatter can take the name and the documented install command breaks before launch.
- **Disposition rationale**: Low/low, but the guard costs minutes and the downside — the documented install command broken at launch — is embarrassing far beyond its probability.
- **Action**: Publish a placeholder 0.0.x of `keel-skills` to npm before the repo (or any README naming the package) goes public. Mitigated by T-004 (placeholder npm publish).
- **Related decisions**: D-001, D-007
