## R-039: Experimental brand shorthand can still read as model-provider support instead of runtime support

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-10
- **Date resolved**:
- **Description**: D-033 defines support as agent-runtime support, but the requested names are also public model or product brands. Even if supported-agent tables stay clean, `--experimental kimi`, `--experimental pi`, detector output, or separate experimental docs can be quoted as "Treenail supports Kimi/Pi" without the Kimi Code CLI or Pi Coding Agent boundary.
- **Disposition rationale**: Medium severity but high likelihood means the
  failure is mostly a naming and surface-drift problem that should be guarded
  while preserving D-033 and D-034. The blast radius is public confusion and
  premature support claims, which are exactly the surfaces Treenail already
  knows how to check.
- **Action**: Keep D-033 and D-034. Guard: use runtime-qualified labels in every
  experimental surface and installer path, e.g. Pi Coding Agent and Kimi Code
  CLI, while keeping short aliases only as CLI conveniences whose help text
  expands to the runtime name. Detector output, unvalidated-adapter docs, and
  release-gate records must say "experimental runtime adapter" and must not
  describe model-provider support. Mitigated by T-054, T-057, T-061, T-062,
  T-063, and T-064.
- **Related decisions**: D-033, D-034
