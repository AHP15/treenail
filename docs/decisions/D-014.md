## D-014: Single semver for the whole repo, starting at 0.1.0

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The skills, the per-provider dist builds, and the keel-skills CLI could version independently or in lockstep. Independent versioning creates an installer-to-skill-set compatibility matrix.
- **Decision**: One semver covers everything: skills, dist, and CLI move together; ~/.keel/VERSION and the npm package version always match. Start at 0.1.0 and tag 1.0 when the multi-agent build and canonical format have proven stable.
- **Rationale**: A compatibility matrix between installer and skill set is pure overhead at this scale. Lockstep versioning makes "what do you have installed" a one-number question, which the update command (D-010) depends on.
