## D-006: Shared runtime lives in an agent-neutral ~/.keel home (overridable via KEEL_HOME)

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: Skill bodies currently hardcode ~/.claude/skills/_shared/scripts/... paths to the shared Python scripts, templates, and conventions files. With three agents installed on one machine, those assets must resolve from any of them without duplication.
- **Decision**: The installer places shared assets (scripts, templates, conventions spec/examples, guide, VERSION) once in ~/.keel/; the build rewrites all skill references to that path, overridable via the KEEL_HOME environment variable. Per-project state conventions (docs/...) are unchanged.
- **Rationale**: One copy means no cross-agent drift on the same machine and stable paths across providers. Per-provider script copies (the alternative) triple the footprint and let the copies diverge silently.
