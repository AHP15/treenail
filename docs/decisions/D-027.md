## D-027: Remove the standalone pipeline guide; fold a curated subset into README

- **Status**: accepted
- **Date**: 2026-07-04
- **Context**: `skills/guide.md` (~480 lines) is the v2 pipeline guide —
  purely human-facing, read by no skill at runtime, referenced only by a
  `README.md` link, `build.py` (`EXTRA_FILES` → `~/.treenail/guide.md`), and
  the smoke test's asset check. It overlaps heavily with the retained
  authoritative `docs/CONVENTIONS-SPEC.md` (schema) and with README's existing
  pipeline/Graphiti/per-agent sections.
- **Decision**: Hard-delete `skills/guide.md` (`git rm`) and its build coupling
  (`EXTRA_FILES`, the copy in `build_treenail_home`, the `guide.md` asset check
  in `smoke-install.mjs`, the `README.md` link). Migrate a curated subset into
  README — the **artifact-layout tree**, a **per-skill pipeline narrative**
  (expanding the existing pipeline diagram), and the **cadence summary table**.
  Everything else (v1→v2 migration, INDEX-format detail, the per-skill
  read-patterns table, edge cases, "why this layout") is **dropped to git
  history**, not relocated.
- **Rationale**: The guide duplicated the go-forward mental model that belongs
  in README and the schema that CONVENTIONS-SPEC.md already owns. Migrating a
  curated subset gives a reader the layout + flow + cadence without re-bloating
  README into a second guide; relocating the deep sections to a new
  `docs/pipeline.md` was rejected as re-creating the guide under another name.
- **Rationale (learning-loss check)**: Weighed against 2026-07-04 Pattern #3
  ("tidiness hides learning"). The guide is reference documentation, not
  calibration — the scars live in `decisions/`, `risks/`, and
  `retrospectives/`, all retained — so dropping it to history erases no
  learning signal.
- **Note (D-006)**: Narrows the shared runtime's shipped contents (no more
  `~/.treenail/guide.md`); not a supersession for the same reason as D-026.
  Clean-replace provisioning removes the stale copy on next `install`/`update`.
