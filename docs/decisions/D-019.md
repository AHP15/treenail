## D-019: CI smoke-runs the installer CLI on Node 22

- **Status**: accepted
- **Date**: 2026-07-03
- **Context**: Surfaced as an unstated premise during the ESM interview: CI runs the Python `_shared` test suite and a dist-sync check but never executes the Node CLI, so a botched CommonJS→ESM conversion (missed `.js` extension, stray `module.exports`) would ship invisibly. T-024 (Windows runner) and T-028 (release-gate checklist) cover broader validation but land later.
- **Decision**: `ci.yml` gains a small smoke step on the existing ubuntu/macos matrix: setup-node 22, then run `node cli/bin/keel-skills.js help` and `detect`. This lands with the ESM change itself.
- **Rationale**: Under D-016's static imports, running any subcommand loads the entire import graph, so ~5 lines of YAML catch the exact regression class this migration risks, immediately. It does not replace T-024 or T-028 — it is a loader-level smoke, not behavioral validation.
