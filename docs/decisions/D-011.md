## D-011: Keep flat skill names in v1; record collision risk

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The 14 skills use flat names (challenge-me, promote, reindex, ...). Generic names could collide with other skill packs in the same agent; impeccable namespaces under its own directory.
- **Decision**: v1 installs keep the current flat names, unchanged. The collision risk is recorded and the naming revisited if real collisions are reported. (Note: the Claude plugin-marketplace channel from D-007 namespaces automatically as keel:<skill>, which is inherent to plugins and unaffected by this decision.)
- **Rationale**: Renaming would ripple through guide.md, cross-skill references, and existing user muscle memory for zero present-day benefit; the distinctive names (challenge-me, red-team-me, triage-risks) make collisions unlikely today. This is cheap to reverse relative to its blast radius now.
