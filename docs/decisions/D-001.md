## D-001: Keep the Keel brand; publish the installer as `keel-skills` on npm

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The pipeline is already named Keel throughout its guide and skills, but the `keel` npm package is taken and keel.sh (Kubernetes) / keel.so (backend platform) are existing dev-tool brands. The installer needs a memorable `npx` entry point.
- **Decision**: Keep "Keel" as the project/brand name and GitHub repo name (namespaced by the owner's account). Publish the installer/CLI as the npm package `keel-skills`, invoked as `npx keel-skills install`.
- **Rationale**: The name is already woven through the pipeline and renaming buys little; GitHub repos are user-namespaced so no collision there. `keel-skills` is free on npm, self-describing, and searchable, whereas `keel-cli` reads like a CLI for the Kubernetes tool.
