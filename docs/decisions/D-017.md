## D-017: Node engine floor for the installer is >=22

- **Status**: superseded
- **Date**: 2026-07-03
- **Date superseded**: 2026-07-03
- **Superseded by**: D-020
- **Context**: `cli/package.json` declared `engines: ">=18"`, but Node 18 and 20 are both past end-of-life as of mid-2026, and the ESM migration (D-016) must choose between shimming `__dirname` via `fileURLToPath` (works on 18) or using `import.meta.dirname` (needs 20.11+). The recommendation was to keep >=18 for npx reach; the owner redirected to the maintained-LTS-only floor.
- **Decision**: `engines` becomes `">=22"`. The `__dirname` usage in `install.js` is replaced with `import.meta.dirname` directly, no shim. The engines field stays advisory (npm's default warning); the bin performs no runtime Node-version check.
- **Rationale**: Only currently-maintained LTS lines are supported, which keeps the code on modern idioms (`import.meta.dirname`) with zero compatibility shims. A runtime version check was judged over-engineering for an installer whose failure mode on ancient Node is an immediate, legible syntax/loader error.
