## D-008: User-level installs only in v1

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: Skills could install per-user (~/.claude and equivalents) or per-project (.claude/skills inside a repo, for teams). The pipeline's current design assumes per-user skills with per-project docs/ state.
- **Decision**: v1 installs at user level only: ~/.claude/skills, and the opencode/Codex user config equivalents. Project-level/team installs are deferred.
- **Rationale**: Matches how the pipeline already works and keeps the installer's path handling simple. Project-level installs multiply questions (gitignore, path rewriting, team version skew) that deserve their own design pass later.
