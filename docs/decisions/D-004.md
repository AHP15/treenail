## D-004: Single canonical skill source compiled per provider by a build step

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: v1 targets Claude Code, opencode, and Codex, whose skill/command systems differ; more agents are planned later. Prior art splits: impeccable compiles one source to per-provider outputs; ecc hand-maintains per-provider directories.
- **Decision**: Maintain one canonical skill source; a small build step compiles per-provider distributions into dist/claude/, dist/opencode/, and dist/codex/. Adding an agent means adding an adapter, not another maintained copy.
- **Rationale**: 14 skills x 3 agents hand-maintained is unmanageable drift, and the roadmap explicitly adds more agents. The skills are mostly markdown plus shared scripts, so adapters stay thin (impeccable's proven model).
