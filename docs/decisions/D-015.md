## D-015: v1 cut line

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: v1 needs an explicit definition of done so scope creep is a decision rather than an accident. The owner adjusted the initially proposed cut by pulling in the Claude plugin marketplace and Windows-native support (the latter forcing the D-009 revision).
- **Decision**: v1 ships when: the repo is public under MIT; the build compiles all 14 skills to dist/{claude,opencode,codex}; `npx keel-skills install|update|detect` works user-level on Windows, macOS, and Linux; the Claude plugin-marketplace listing works; and the README covers quickstart, manual copy, and the pipeline guide. Explicitly not in v1: website, project-level installs, monetization/pro tier, and agents beyond the three.
- **Rationale**: This is the minimal slice consistent with every prior decision while including the two additions the owner judged launch-critical (marketplace reach for Claude users, Windows for audience size). Everything excluded has a later natural slot and nothing in v1 forecloses it.
