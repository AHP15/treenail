## D-021: Rename the project to Treenail

- **Status**: accepted
- **Date**: 2026-07-04
- **Context**: D-001 kept the Keel brand despite the `keel` npm name being taken and two established dev-tool brands (keel.sh, keel.so) owning the search space. The owner wants a name that expresses the pipeline's actual identity — deep decision trees and determinism — and, since a rename is being paid for anyway, a clean namespace this time: bare npm name free, no established dev tool on the name, distinctive in search. Candidates were drawn from tree-anatomy nouns (the pipeline's own vocabulary is tree-shaped) and gated on namespace: taproot, heartwood, cambium, bole, xylem, pith, and lignum are npm-taken; trunnel collides with Tor's binary-format DSL; duramen collides with a dormant Java event bus.
- **Decision**: The project is renamed **Treenail** (`treenail` in code, "Treenail" in prose). A treenail is the wooden peg that permanently fastens ship timbers to the keel: the tree is literal, "nailing a decision down" is the deterministic act the pipeline performs, and the old brand survives in the lineage. Verified at decision time: `treenail` is free on npm and has zero software collisions (woodworking term only).
- **Rationale**: It is the only candidate that scores on both requested axes (tree + determinism) *and* passes the clean-namespace gate with no compromise, while keeping a narrative thread back to Keel. Runner-up duramen (botanical heartwood) was strong on depth/immutability but weaker on "deciding" and carried a minor collision.
- **Supersedes**: D-001
