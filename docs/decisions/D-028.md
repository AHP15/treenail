## D-028: Reach agent parity by reframing the message, not by degrading Claude Code

- **Status**: accepted
- **Date**: 2026-07-08
- **Context**: We want to market Treenail as offering equal support across
  its three agents (Claude Code, Codex CLI, opencode) and to keep that claim
  extensible as new agents are added. A proposal on the table was to force
  sameness by neutralizing Claude Code's edge — specifically to disable the
  `AskUserQuestion` tool "because it hides the recommended decision and its
  rationale." Two facts checked against the codebase contradict the premise:
  (1) `grep` finds zero references to `AskUserQuestion` in `skills/`; the
  skills are agent-neutral (D-005) and already emit the recommendation and
  reasoning as prose *before* any tool renders (`challenge-me/SKILL.md:28`),
  and Claude Code marks the first option `(Recommended)` — so the rationale is
  not hidden. (2) `AskUserQuestion` is a Claude Code *harness* tool, not
  something Treenail's skills invoke, so it cannot be shipped-disabled to
  end users; the most we could do is instruct skills to avoid option lists,
  which only degrades the experience we dogfood daily.
- **Decision**: Achieve "equal support" by reframing the public message, not
  by removing capability. `AskUserQuestion` and Claude Code's structured
  selectable-option interview stay exactly as they are — treated as an
  unadvertised enhancement, not a disadvantage to neutralize. The
  "disable AskUserQuestion" proposal is rejected.
- **Rationale**: Leveling down makes the product worse to make one marketing
  sentence simpler, rests on a false premise (the rationale is already shown
  in prose), and is not even technically shippable (harness tool). The spike
  already establishes that all three agents run the complete pipeline with
  full fidelity, so parity is available truthfully without touching the
  product — the honest fix is in the words, not the code.
- **Note (R-004)**: Keeps R-004 (interactive core degrades on non-Claude
  agents) live and accurately scoped — the surface difference is real and
  disclosed, not erased.
