## D-031: A new agent earns the "supported" label only by passing parity validation

- **Status**: accepted
- **Date**: 2026-07-08
- **Context**: The equal-support message (D-028, D-030) is intended to extend
  to new agents "soon." Without a standing bar, each new agent would be
  advertised on assumption or a quick smoke, which is exactly the
  notional-claim trap retrospective watch-for P4 flags. The reframed parity
  validation doc (D-029) already documents a repeatable method.
- **Decision**: An agent is advertised as supported only after it passes the
  parity validation — the full pipeline run end-to-end (challenge-me →
  red-team-me → task-brief) with records auditing clean (0 blockers) and the
  interview protocol (one question at a time, recommendation-first, pushback)
  intact. Until it passes, an agent is not listed as supported. The D-029 doc
  is the reusable template for this validation.
- **Rationale**: The current claim is defensible only because a spike earned
  it; making validation the standing gate keeps "equal support" honest as the
  list grows rather than letting it decay into aspiration. Advertising
  optimistically would reintroduce the un-validated-but-claimed exposure the
  project already carries as R-004/R-005.
