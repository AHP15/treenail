## D-022: One name across every surface — brand, npm, CLI, env var, home dir, plugin

- **Status**: accepted
- **Date**: 2026-07-04
- **Context**: Under Keel the naming diverged by surface: brand "Keel", npm package `keel-skills` (bare name taken), env var `KEEL_HOME`, runtime dir `~/.keel`, plugin name `keel`. The clean-namespace gate in D-021 means the bare npm name is now free, removing the only justification for the split.
- **Decision**: The single token `treenail` is used uniformly: npm package `treenail` (`npx treenail install`), CLI bin `treenail`, env var `TREENAIL_HOME`, runtime dir `~/.treenail`, plugin manifest name `treenail`, GitHub repo `treenail`. The `-skills` compound dies with the rename.
- **Rationale**: One token everywhere is simpler to teach, grep, and document, and eliminates the keel-vs-keel-skills ambiguity users would otherwise have to learn. The mechanical constraints this imposes (lowercase, hyphen-free, valid env-var prefix) were part of candidate gating in D-021.
