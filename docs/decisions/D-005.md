## D-005: Claude-style SKILL.md is the canonical authoring format, written agent-neutrally

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: Given D-004's build step, a canonical source format is needed. The 14 existing skills are already Claude SKILL.md files with frontmatter; inventing a neutral schema would require migrating all of them.
- **Decision**: Author skills in the existing Claude SKILL.md + frontmatter format; the build transforms it for opencode and Codex. One authoring rule: skill bodies use agent-neutral phrasing ("ask the user", not "use AskUserQuestion") so skills degrade gracefully on agents lacking Claude-specific tools; the build injects any per-provider preamble or notes.
- **Rationale**: Zero migration cost for the existing skill set, and SKILL.md is the richest and most widely understood of the three formats. A bespoke neutral schema is cleaner in theory but is real work now for a format nobody else knows.
