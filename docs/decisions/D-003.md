## D-003: The repo is the canonical source; ~/.claude/skills becomes an install target

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The pipeline currently lives and evolves directly in the owner's ~/.claude/skills. Once a distribution repo exists, two copies exist and one must be authoritative.
- **Decision**: The GitHub repo is the single source of truth. The owner's live ~/.claude/skills becomes an installed copy (or symlink) produced by the same install path users run. Requires a one-time migration of the current skills into the repo.
- **Rationale**: Developing in ~/.claude and syncing snapshots outward guarantees drift and means the shipped install path is never dogfooded. Making the repo canonical means every release is tested by the owner's own daily use of the real installer.
