## D-007: Distribution channels — npx installer, manual copy, and Claude plugin marketplace

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: v1 needs an install story covering three different agents with one coherent update path. Prior art uses npx CLIs (impeccable), install scripts + marketplace plugins (ecc), and plain copying.
- **Decision**: Primary channel is the npx CLI (`npx keel-skills install|update|detect`) which detects present agents and installs per-provider files. The README also documents plain git-clone/manual copy from the committed dist/. Additionally, v1 ships as a Claude Code plugin on the plugin marketplace for Claude users (added to the v1 cut by the owner).
- **Rationale**: The CLI gives one cross-agent entry point plus a natural update command; committed dist/ keeps zero-tooling copy possible; the marketplace channel meets Claude users where they already install plugins. Plugin installs are namespaced and updated by Claude's plugin system, which coexists with the CLI-managed user-level install.
