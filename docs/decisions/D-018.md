## D-018: Fix `files` to include `lib/` now; prepack/dist bundling stays with the publish task

- **Status**: accepted
- **Date**: 2026-07-03
- **Context**: Surfaced as an unstated premise during the ESM interview: `cli/package.json` has `"files": ["bin/"]`, so the published package omits `lib/` and the bin cannot resolve `../lib/...` at all — and under D-016's static imports even `help` would crash. Separately, the comment in `install.js` claims prepack copies `dist/` into the package, but no prepack script exists.
- **Decision**: Add `"lib/"` to `files` as part of the ESM change. The missing prepack script and dist-bundling wiring are explicitly left to T-004, which owns the real publish flow.
- **Rationale**: The `files` fix is a one-line correctness change riding a commit that edits package.json anyway, and D-016 raised its stakes from "some subcommands break" to "every invocation breaks". The prepack wiring is real publish-flow design that belongs with the in-progress publish task rather than smuggled into a module-system migration.
