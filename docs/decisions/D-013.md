## D-013: Graphiti stays optional; skills ship as-is and setup is the user's job

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: graph-sync and the graph-query hooks in other skills depend on an optional Graphiti knowledge graph, and already degrade gracefully (skip with no output) when it is not configured.
- **Decision**: Ship graph-sync and the query hooks unmodified in all provider builds. The installer neither installs nor checks Graphiti; the README gets a short optional-setup section.
- **Rationale**: The graceful-degradation behavior already exists, so excluding the skills would mean maintaining an exclusion list to avoid shipping working code. Bundling Graphiti setup would drag a heavyweight optional dependency into everyone's install path.
