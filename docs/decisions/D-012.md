## D-012: Repo layout skills/ + cli/ + committed dist/ + public dogfooded docs/

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The repo must host the canonical source (D-003), the build outputs (D-004), the npm CLI (D-007), and Keel's own planning records somewhere. Manual-copy users need prebuilt provider files available in the repo itself.
- **Decision**: Layout: skills/ (canonical SKILL.md source + _shared + _templates), cli/ (the keel-skills npm package), dist/ (committed per-provider builds: claude/, opencode/, codex/), docs/ (Keel's own decision/risk/task records, public). CI runs the _shared script tests and verifies dist/ is in sync with source.
- **Rationale**: Committed dist/ is what makes zero-tooling manual copy possible and is prior art in impeccable; the CI sync check neutralizes its staleness risk. Public docs/ makes the repo its own best demo — the pipeline's records for building the pipeline.
