## D-009: Python 3 is the one scripted-runtime dependency; Windows, macOS, and Linux all officially supported

- **Status**: accepted
- **Date**: 2026-07-02
- **Context**: The _shared scripts are Python 3 plus one bash script (mint-id.sh), while the installer is Node. Initially resolved as "macOS/Linux official, Windows via WSL best-effort", then revised in the same session when the owner pulled Windows-native support into the v1 cut (D-015).
- **Decision**: Keep Python 3 as the required scripted runtime (no Node port of the scripts in v1). All three OSes are officially supported: the installer verifies a working Python 3 and detects the right command per platform (python3 / py / python), the build rewrites script invocations accordingly, and mint-id.sh is ported to Python so no bash-only scripts remain.
- **Rationale**: Porting ~10 audited scripts to Node would delay v1 for no user-facing gain; Python 3 installs cleanly on all three OSes. Eliminating bash-isms plus interpreter detection is the minimal work that makes native Windows genuinely supported rather than best-effort.
