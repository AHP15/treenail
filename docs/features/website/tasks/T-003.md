- **Notes**: The derive-don't-duplicate half of D-005. Loud-failure hardening against intra-file drift is T-004; consumers of the generated pages are T-010 (pipeline) and T-011 (record conventions). `scripts/generate-derived.mjs` reads sibling repo files directly (`../skills/*/SKILL.md`, `../docs/CONVENTIONS-SPEC.md`) and emits one skill-reference page per SKILL.md (14) plus record-schema pages quoting the spec's field lists (decisions/risks/tasks) into `content/docs/reference/{skills,records}/`. Wired into `prebuild` and `predev` (generator → fumadocs-mdx) so it runs as part of the site build; verified by a full `next build` (29 static pages incl. derived routes). Output is gitignored (single-sourced, regenerated each build). Spec sections are quoted inside a fenced block so `<Title>`-style placeholders can't break MDX. Extraction helpers are exported for T-004's assertions.
