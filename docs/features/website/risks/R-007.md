## R-007: Launching on the vercel.app subdomain bakes a throwaway public URL into README, npm, SEO, and backlinks

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: mitigate
- **Date**: 2026-07-05
- **Date resolved**:
- **Description**: D-013 defers the custom domain and launches on `treenail.vercel.app`, treating the subdomain as costless interim. But once live it becomes a public string that propagates into places that outlive it: the repo README, the npm package `homepage`/links, search-engine indexes, and any external backlinks or social shares accumulated pre-domain-switch. When the custom domain is later adopted, that link equity and every already-circulated URL must be migrated with redirects the vercel.app host may not let you fully control — the same "new public strings are expensive, and their internal blast radius is under-counted" pattern the retrospective calls out (Pattern #1, Watch-for #6), applied to a URL instead of a name.
- **Disposition rationale**: Launching on the subdomain (D-013) is the right call — it correctly defers the domain-diligence cost — but the migration blast radius is reducible now with cheap discipline, so mitigate rather than accept the later pain wholesale. The redirect work itself is genuinely deferred to the domain-adoption task; the preventive half is a now-action.
- **Action**: Mitigate on two fronts: (now) don't propagate the throwaway URL into durable external surfaces — reference the site through a single centralized constant/relative links, keep the absolute `treenail.vercel.app` out of README/npm `homepage` where a bare "docs" link or the GitHub repo can stand in until the domain lands, and set a self-referential canonical so SEO equity isn't fragmented; (at domain adoption — the D-013 follow-up task) carry the 301 redirect map from the vercel.app host and update the centralized constant in one place. Trigger for the deferred half: the custom-domain-adoption task. Tracked by T-019 (now-half) and T-020 (deferred redirect migration).
- **Related decisions**: D-013
