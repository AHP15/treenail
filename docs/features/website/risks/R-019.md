## R-019: The landing heading "The full pipeline on every agent" over-claims beyond the validated set that D-031 gates support to

- **Severity**: medium
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-08
- **Date resolved**:
- **Description**: D-019 replaces the ranked heading with a universal-absolute
  parity frame ("every agent"). But project D-031 restricts the "supported"
  claim to agents that have passed parity validation — currently exactly three.
  "Every agent" reads to a visitor as "any agent you bring," so a user who runs
  Treenail on an unvalidated fourth agent and hits degradation was promised
  something the product deliberately does not claim. This is the same
  publish-promises exposure as the archived R-005, but specifically introduced
  by the new absolute phrasing that the old bounded "best/full on these three"
  copy did not carry.
- **Disposition rationale**: The over-claim lives in illustrative heading copy,
  not in D-019's binding structural decision (chips + detail-move), so no
  supersession is needed — a wording constraint closes it while keeping the
  decision. Accepting an unbounded claim would contradict the whole cycle's
  honesty stance (project D-030).
- **Action**: Guard the landing copy: the parity claim must be scoped to the
  validated set — name the agents or say "every *supported* agent," never
  unbounded "every/any agent." Re-pin the copy to the validated parity matrix
  (project D-029) per this feature's standing tier-accuracy gate (retrospective
  watch-for #6), and have the project-level claim CI guard (project scope, from
  R-032/R-034) assert no unbounded-universal phrasing on the support surfaces.
  Mitigated by T-024 (landing claim scoped to the validated set, no unbounded
  "every/any agent"). Re-triaged 2026-07-08 (mitigation-complete: T-024 done):
  mitigate → accept — the landing claim is scoped to the validated set and
  unbounded universal phrasing is guarded by the project support-surface CI
  check; residual acceptable.
- **Related decisions**: D-019
