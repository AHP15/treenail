## R-011: Truncating the IP for privacy coarsens the limiter key, so shared-egress users get throttled for a stranger's submissions

- **Severity**: medium
- **Likelihood**: low
- **Disposition**: fix
- **Date**: 2026-07-05
- **Date resolved**: 2026-07-05
- **Date archived**: 2026-07-07
- **Action**: Superseded by D-017 — removes the failure mode.
- **Related decisions**: D-016
- **Summary**: Truncating the IP for privacy folds NAT/corporate/VPN users into one bucket, so once any one submits the rest are throttled for a submission they never made — hitting the developer-behind-a-VPN audience, worst on a launch spike. Retired by the same D-017 supersession that dropped per-client keying.
