## R-015: Turnstile adds an undisclosed Cloudflare data flow that the "cookieless / no-consent-banner / zero-PII" claim omits

- **Severity**: medium
- **Likelihood**: high
- **Disposition**: mitigate
- **Date**: 2026-07-05
- **Date resolved**:
- **Description**: D-017 asserts Turnstile "narrows R-004 further" because the limiter no longer processes IPs, and D-015/D-006 build a public posture of cookieless analytics, no consent banner, and zero PII. But the Turnstile widget itself is a third-party Cloudflare script that loads on any page carrying a form, sends the visitor's IP and browser signals to Cloudflare, runs fingerprinting-adjacent challenge logic, and in interactive/managed mode can set a Cloudflare clearance cookie — all before any submission. That makes Cloudflare a new data processor and a new third-party origin the current claim does not mention. The privacy disclosure (R-004, T-015) and the no-consent-banner assertion were scoped to analytics and the removed IP limiter; if they ship without accounting for Turnstile's collection, the published privacy claim is materially incomplete for the same reason R-004 flagged — the marketing posture outruns what the page actually does.
- **Disposition rationale**: The fix is not to drop Turnstile but to make the published claim honest about it — the same content-accuracy guard R-004 already applies to the privacy note, extended to cover the new Cloudflare data flow. So mitigate, folded into the existing privacy-disclosure work rather than a new decision.
- **Action**: Mitigate by extending the privacy disclosure (the R-004 mitigation, T-015) to (1) name Cloudflare Turnstile as a third-party processor and describe what it collects (IP + browser signals sent to Cloudflare on load of any form-bearing page); (2) re-verify the "no consent banner required" claim against Turnstile's actual behavior in the chosen mode, and confirm whether managed mode sets any cookie — if it does, qualify or drop the "cookieless" wording accordingly; (3) block launch on the disclosure matching the deployed reality, per the R-004 content-accuracy gate. Overlaps R-004/T-015 — treat as the same disclosure surface, not a separate banner.
- **Related decisions**: D-017, D-006, D-015
