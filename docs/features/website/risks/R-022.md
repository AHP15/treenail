## R-022: Two hand-maintained copies of the surface-note sentence (landing + doc) can drift, so the site disagrees with itself about the honesty caveat

- **Severity**: low
- **Likelihood**: medium
- **Disposition**: accept
- **Date**: 2026-07-08
- **Date resolved**:
- **Description**: D-021 deliberately duplicates the neutral surface-note
  sentence — one instance on the landing page, one in the doc — rather than
  single-sourcing it. Because both are edited by hand, a later change to one
  (rewording the caveat, or updating it when the agent set changes per R-020)
  can leave the other stale, so the two credibility-critical surfaces state the
  surface difference differently. This is the same single-sourcing-drift failure
  mode the feature already recorded for derived docs (archived R-002), now on
  the parity claim specifically, and D-021 chose the duplication without noting
  how the two copies stay in sync (project T-050's guard scope over phrasing
  equality is unspecified).
- **Disposition rationale**: Low severity — the two instances are one short
  sentence each, the duplication is a deliberate D-021 choice, and drift only
  surfaces to a reader who views both surfaces and notices a wording delta.
  R-020's mitigation already forces a re-read of the note at the moment it is
  most likely to change (a new agent), so a dedicated string-equality guard
  would be ceremony disproportionate to the blast radius the retrospective
  cautions against.
- **Action**: none — accepted. If the project-level support-surface CI guard
  (project scope, from R-032/R-034) is being built anyway, a
  both-instances-present-and-consistent assertion is a near-free add, but it is
  not required to close this risk.
- **Related decisions**: D-021
