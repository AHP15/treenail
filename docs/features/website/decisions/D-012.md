## D-012: Animated interactive pipeline centerpiece; no live in-browser playground in v1

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: The pipeline is the landing page's central visual (D-009 section 4). Investment ranges from a static SVG to a full in-browser demo that generates real D/R/T records.
- **Decision**: Build the pipeline as an animated, interactive diagram — a scroll-linked reveal where each joint/peg locks into place, with hover/tap states surfacing what each skill reads and writes — plus tasteful micro-interactions elsewhere (copy buttons, card lifts). All CSS/SVG-driven, honoring `prefers-reduced-motion` with a static fallback. Exclude a live "playground" that runs a planning session in-browser from v1.
- **Rationale**: The animated pipeline delivers the "stunning" wow on the exact element that explains the product, at manageable build cost, and the reduced-motion fallback keeps it accessible. A live playground was rejected for v1: it needs the agent runtime and is a large lift for a marketing site, disproportionate to its marginal persuasion value.
