## D-010: Documentation is reference-complete across five top-level sections

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: The brief is to document the agent harness "in detail." Depth could range from a lean MVP (getting started + concepts) to full reference coverage of every skill and record convention.
- **Decision**: Ship reference-complete docs in five top-level sections: (1) **Getting Started** — install (npx/manual/plugin), Node/Python prereqs, first skill run; (2) **Core Concepts** — the planning spine, the decision/risk/task model, scopes (project vs feature), INDEX discipline, `O(active work)`, archiving; (3) **The Pipeline** — overview + one page per skill (the 10 pipeline skills + 4 supporting), reference pages derived per D-005; (4) **Record Conventions** — the D/R/T schema, Evidence anchors, ID minting, sourced from `CONVENTIONS-SPEC.md`; (5) **Reference** — CLI (`detect`/`install`/`update`), `TREENAIL_HOME`, agent support tiers, optional Graphiti setup.
- **Rationale**: "In detail" reads as reference-complete, and the five sections mirror the repo's real structure so the D-005 derived pages line up 1:1 with what exists. A lean-MVP-first cut was rejected as under-delivering on the explicit "in detail" ask. A guided end-to-end tutorial track was considered a nice-to-have but not required for v1 (the getting-started page carries the minimal walkthrough).
