## D-021: The neutral surface-note sentence rides with the parity claim on every surface that makes it

- **Status**: accepted
- **Date**: 2026-07-08
- **Context**: Project D-030 mandates "exactly one neutral sentence" noting the
  surface difference (interview questions render as selectable options on Claude
  Code and as prose on the others — same protocol). But the website asserts the
  parity claim in two independently-reached places: the landing page (D-019) and
  the `supported-agents` doc (D-018). That leaves open whether "one sentence"
  means one per site or one per claim instance.
- **Decision**: Read project D-030's "exactly one sentence" as *one per claim
  instance*. The neutral surface-note sentence travels with the parity claim
  wherever it is made — one on the landing page, one in the doc — and is never
  stacked (no piling up multiple caveats in a single spot). (The README is a
  sibling surface outside this website feature's scope; it carries the same claim
  under project T-049.)
- **Rationale**: A visitor who lands directly on either page must see the honest
  caveat next to the claim; putting the note in only one place leaves the other
  surface making an unqualified "full pipeline on all three" claim — the exact
  credibility trap project D-030 exists to prevent, falsifiable in a single
  side-by-side session. Binding the note to the claim (not to a canonical page)
  keeps every assertion self-caveating while still honoring D-030's
  "don't over-caveat" cap.

  reads "honest, bounded degradation (Best vs Full), never parity," which now
  contradicts project D-030 and these decisions. It is stale implementation
  prose, not a live decision, and must be corrected when project T-049 edits the
  file.
