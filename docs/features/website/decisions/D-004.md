## D-004: Site lives in this repo under `site/`, with Vercel root set to that subdirectory

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: The site can live in this repo or a separate `treenail-site` repo. The docs source-of-truth strategy (D-005) depends heavily on how easily the site build can read the repo's canonical files (`README.md`, `docs/CONVENTIONS-SPEC.md`, skills' `SKILL.md`).
- **Decision**: Keep the site in this repo in a `site/` subdirectory; configure Vercel's project root to `site/`. Single-sourcing docs then reads sibling repo files directly at build time.
- **Rationale**: A monorepo makes the hybrid single-sourcing of D-005 trivial (direct relative reads), whereas a separate repo would force a submodule/npm-dep/sync step to reach the same files. It also preserves the project's one-repo discipline (product D-012, committed `dist/`). Cost accepted: `.gitignore`/CI must keep the site's Node tooling from polluting the product package.
