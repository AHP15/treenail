## D-003: Fumadocs as the documentation layer on top of Next.js

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: The site pairs a bespoke, "stunning" landing page with reference-complete documentation that needs a sidebar, table of contents, search, and MDX. Next.js is the base framework (D-002).
- **Decision**: Use Fumadocs (Next.js App-Router-native docs framework, MDX-based) for the documentation surface. The landing page remains an ordinary Next route with full design freedom.
- **Rationale**: Fumadocs supplies the docs shell (sidebar/TOC/search/MDX) for free while leaving the marketing surface unconstrained, unlike Nextra whose opinionated theme fights bespoke landing design. Fully hand-rolling the docs shell (plain MDX) was rejected as reinventing solved problems (sidebar, search, TOC) for no design gain on reference pages.
