## D-015: Ancillary v1 defaults — built-in search, cookieless analytics, English-only, dual theme

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: Several low-leverage site concerns need a settled default without their own deliberation: docs search, web analytics, localization, and theming. Recording them prevents each from being silently re-decided during implementation.
- **Decision**: (1) **Search** — Fumadocs' built-in static search (Orama); no Algolia. (2) **Analytics** — Vercel Analytics, cookieless, no consent banner required; no Google Analytics. (3) **Localization** — English-only for v1; no i18n scaffolding. (4) **Theming** — ship both dark and light, theme-aware, per the impeccable/artifact defaults and D-011.
- **Rationale**: Each default takes the lowest-friction option consistent with the chosen stack (Fumadocs, Vercel) and the individual-developer, pre-1.0 scope: built-in search avoids a third-party search vendor, cookieless analytics avoids a consent-banner obligation, English-only avoids premature i18n cost, and dual theming is table stakes for a modern dev-tool site. Any of these is cheaply revisited later.
