## D-009: Landing page follows an eight-section narrative arc

- **Status**: accepted
- **Date**: 2026-07-05
- **Context**: With a pain-led hero (D-008) and an animated pipeline centerpiece (D-012), the landing page needs a section flow that front-loads the problem and lands the pipeline as the mid-scroll visual hook.
- **Decision**: Order the landing page as: (1) Hero — "stop your coding agent losing the plot" + `npx treenail install` CTA + Docs/GitHub secondary; (2) The problem — drift, forgetting *why*, re-litigation; (3) The core idea — the planning spine, records in your repo; (4) The pipeline — the animated centerpiece; (5) Why it stays fast — reads `O(active work)`; (6) Supported agents — Claude Code/Codex/opencode with honest tiers; (7) Quickstart — the three `npx` commands; (8) Newsletter + contact CTA, then footer.
- **Rationale**: This arc front-loads the pain per D-008 and positions the pipeline diagram where a scrolling reader is primed to understand it. A leaner Hero→problem→pipeline→quickstart cut was considered but rejected as dropping the scaling and agent-support proof points that answer real objections. A social-proof band was deferred for lack of pre-launch proof.
